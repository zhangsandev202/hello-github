# hello-github

这是我第一个推送到 GitHub 的仓库。

## 它是干什么的

没有特别用途，就是用来验证「本机 → GitHub」这条路是通的：
能提交、能推送、能拉取。跑通之后，你可以把任何真实项目放进来。

## 当前状态

- 本地仓库：已初始化（分支 `main`）
- 首次提交：已完成
- 远端仓库：待你在 GitHub 上创建后接入

## 怎么继续

见同目录上一级的《从零开始-GitHub操作手册.html》。

## 我用到的三个命令（记住这三条就够用了）

```
git add -A                       # 把改动放进"待提交"区
git commit -m "说明这次改了什么"   # 存成一个版本
git push                         # 传到 GitHub
```

另外两个常用：

```
git pull                         # 把 GitHub 上的更新拉下来
git status                       # 看现在有什么改动
```
